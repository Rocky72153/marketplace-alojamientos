# Equivalencias del historial

El 12 de noviembre de 2026 se preparó una reescritura autorizada de mensajes de integración. Los árboles de archivos, padres, autores, responsables de commit y fechas de los commits reescritos se compararon con el respaldo anterior. La tabla [historial-commit-map.csv](historial-commit-map.csv) relaciona cada identificador anterior con el equivalente reescrito.

Los resultados de CI, aprobaciones y firmas corresponden a los identificadores originales; no se atribuyen automáticamente a los nuevos. Las evidencias históricas conservan sus referencias originales y la tabla permite localizar sus equivalentes en las ramas actuales. Las firmas de los commits reescritos no se pueden conservar como válidas. GitHub puede conservar las versiones originales en solicitudes de cambios y otras referencias históricas.

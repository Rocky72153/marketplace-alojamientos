1. Abrir el intercambio original en la herramienta de IA.
2. Capturar pantalla(s) donde se vea el prompt completo y la respuesta completa; si son varias capturas, mantener el orden.
3. Conservar la captura original, sin editar texto/fecha/hora. Si el sistema no muestra fecha/hora del intercambio, anotar la fecha/hora local visible o exportada de forma verificable y explicar la limitación.
4. Registrar qué artefacto del proyecto fue afectado, qué se aceptó, qué se verificó y qué se corrigió manualmente.
5. No incluir claves, tokens, contraseñas, datos personales innecesarios ni información privada de terceros.
6. Guardar archivos en esta carpeta con nombres `EV-IA-XX-YYYYMMDD-HHMM.png` y actualizar la tabla. Las capturas deben ser reales; no se crean automáticamente desde este documento.
